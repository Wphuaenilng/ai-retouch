## 0. 先确认一件事：现在是"真模型"还是"占位图"

默认配置（`.env` 里 `PROVIDER_PRIORITY=mock`）**不接任何模型 API**，所有 AI 功能返回一张带灰格边框的占位图。这不是坏了，是用来验证链路与界面交互的。

看到占位图 = 当前是 Mock 模式。想出真效果，需要管理员在 `.env` 里填 `ARK_API_KEY`（火山方舟 Seedream）或 `DASHSCOPE_API_KEY`（阿里云百炼万相），并把 `PROVIDER_PRIORITY` 改成 `seedream,mock`，然后重启服务。详见 [§9 管理员](#9-管理员)。

## 2. 五分钟第一次修图

1. 进「工具箱」，点右上角 **上传新图**，选一张照片（PNG / JPEG / WebP，≤20MB）。
   浏览器会先在本机压出一份"编辑副本"（最长边 2048）再上传，所以大图也不会卡。
2. 左侧选一个功能，比如 **抠图**。右侧参数默认值就能用，点 **抠图 · 约 ¥0.03**。
3. 中间出现 **显影中 42%** 的进度条 —— 数字来自服务端上报的真实进度（Mock 上游是固定的模拟节奏，不代表真实模型耗时）。
4. 完成后自动变成 **前后对比滑杆**：左右拖动中线看差别，左边是处理前，右边是处理后。
5. 满意就点 **进入编辑台** 继续细修，或 **存为新项目** 留着以后改。

一句话：**上传 → 选功能 → 执行 → 拖滑杆看对比 → 导出**。

### 本地功能（免费、即时、可撤销）

- **调色**：表单有 11 个参数，实际效果分三档（详见 [03-实现说明.md](./03-实现说明.md) §3.3）：
  - 真的生效：亮度、曝光、对比度、饱和度、色温与色调（用色相近似，不是白平衡级精度）；"黑白"= 饱和度 -1。
  - **近似实现**：高光/阴影被折进亮度，暗角与褪色是叠一层渐变/纯色矩形。
  - **暂时无效**：锐化（Konva 核心滤镜没有真锐化，任务 3.0/5.x 的 WebGL 管线才有）。
  - 参数范围：前 8 个 -1~1，锐化/暗角/褪色 0~1。**改完要提交才作用到图层**（可撤销），不是拖动中实时预览。
- **裁剪 / 变换**：比例裁剪、旋转、水平/垂直镜像。表单里的 `cropRect`（指定裁剪矩形）暂未开放。
- **导出**：PNG / JPEG / WebP，1× 或 2×，JPEG/WebP 可调质量。**导出按文档原始尺寸出图**，不受当前缩放与平移影响。

在工具箱点这三个本地功能，会直接把你带进编辑台 —— 因为它们需要画布。

## 5. 对话式修图（最省事的用法）

进入编辑台后，右侧就是对话框。直接说人话：

```
把背景换成米白摄影棚，裁成 1:1，再亮一点
```

会发生三件事：

1. **拆计划**：AI 给出步骤卡片（最多 6 步），标出哪几步是云端、哪几步是"本地"（本地步骤免费）。
2. **你把关**：点 **确认执行** 才开始；不想做就点 **取消**。
3. **逐步跑**：每步实时显示"完成 · 1.5s · ¥0.26"，画布跟着变。

### 出错了怎么办

某一步失败（常见是模型超时）时，**已完成的步骤不会丢**，后面的步骤标为已取消。此时你有三个选择：

- **重试本步**：只重跑失败的那一步，然后自动继续往下。
- **跳过并继续**：不要这一步的结果，直接做后面的。
- **取消**：整个计划停掉，画布停在当前状态（照样能撤销）。

### 怎么写指令效果好

| 想做的事 | 建议说法 |
| --- | --- |
| 改观感 | "再亮一点""暖一些""转黑白""加点暗角"（小幅度，AI 会翻译成 ±0.15 这类参数） |
| 换背景 | "背景换成纯白"（纯色最稳）或"换成米白摄影棚，柔和顶光" |
| 局部处理 | **先在画布上涂抹选区**（见 §6），再说"去掉我圈起来的东西""把选区里换成深色木桌" |
| 改尺寸 | "裁成 1:1""扩成 16:9""放大 2 倍变清晰" |

做不到的事（比如"把这张图做成 15 秒视频"）会明确拒绝并告诉你它能做什么，不会硬凑一个错误结果给你。

## 6. 涂抹选区（消除和局部替换的前提）

1. 在编辑台画布 **左下角工具条** 点 笔刷图标（或先选「消除」功能，再点笔刷）。
2. 在图上涂抹要处理的地方。白色区域就是要动的部分，半透明显示。
3. `[` 和 `]` 缩小 / 放大笔刷；点 × 清空重涂。
4. 涂完会自动上传为选区遮罩，屏幕下方提示"选区已就绪，可以执行消除或局部替换"。
5. 这时再点「消除 / 去水印」或「局部替换」的执行按钮。

涂抹比精确描边更好用 —— 模型会自动往外扩一点补全，稍微涂过界没关系。

## 7. 编辑台进阶

### 看片与对比

- **滚轮**：以光标为中心缩放；点 **适配** 回到整图。缩放百分比在画布左下角，图片像素尺寸在右下角。
- **手**（导轨最下方）：进入拖拽平移模式。
- **`\`** 或顶栏对比按钮：**前后对比**。左边显示原图、右边显示当前合成结果，拖动中线比较。

### 图层

- 点图层行选中；AI 结果会替换当前选中层的图源，所以"当前图层"决定结果落在哪。
- 眼睛图标显隐，× 删除（至少保留一层）。
- **接触印样**（底部胶片条）：每次 AI 结果都留一帧，点任意一帧就把当前层切回那一版 —— 相当于可视化的"历史版本"。

### 撤销与保存

- `Ctrl/⌘ + Z` 撤销，`Shift + Ctrl/⌘ + Z` 重做，最多 50 步。**AI 结果也能撤销**，所以放心试。
- 改动后约 1 秒自动保存，顶栏显示"未保存…"→"已保存 14:32"；`Ctrl/⌘ + S` 立即保存。
- 关掉页面不丢：项目列表里点进来就是上次保存的样子。

### 快捷键一览

| 键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + Z` | 撤销 |
| `Shift + Ctrl/⌘ + Z` | 重做 |
| `Ctrl/⌘ + S` | 立即保存 |
| `[` `]` | 笔刷变小 / 变大 |
| `\` | 前后对比开关 |
| 滚轮 | 以光标为中心缩放 |
| Enter / Shift+Enter | 发送指令 / 换行 |

## 8. 配额、花费与限制

- 每人每天默认 **30 次** AI 调用（管理员可调），本地功能不计次。用完提示"今日 30 次已用完，明天 0 点重置"。注意"0 点"按**服务器本地时区**结算：容器跑在 UTC 时，国内用户实际是早上 8 点重置。
- 全站有 **每日成本熔断**（默认 ¥200）：触发后所有人都暂时不能用 AI 功能，这是防止误操作的保险。
- 上传限制：单张 ≤20MB、像素总量 ≤4000 万。服务端能收 PNG / JPEG / WebP / GIF，但**文件选择框只放开 PNG / JPEG / WebP**（GIF 需要先转格式）。
- 一次修图的实际花费：抠图约 ¥0.03，多数编辑约 ¥0.26，超分约 ¥0.12。按默认配额算，一个人一天全用满也就几块钱。

**看自己的用量**：顶栏"今日 12/30"；管理页能看到每人的花费。

## 9. 管理员

### 本机启动与停止

```bash
cd ai-retouch
cp .env.example .env     # 第一次
pnpm install
pnpm dev                 # 前端 5173 + 后端 8787，Ctrl+C 停止
```

### 管理页（右上角「管理」，仅管理员可见）

- **今天**：成本 / 预算、队列水位、内容审核状态。
- **上游**：Seedream / 万相 / Mock 是否可用（没配 key 的显示"未配置 API Key"）。
- **邀请码**：一键生成 3 个，点输入框即全选，方便复制发出去。
- **用户与配额**：直接改某个人的每日次数，失焦即保存。

### 接真实模型

编辑 `.env`：

```
PROVIDER_PRIORITY=seedream,mock
ARK_API_KEY=<火山方舟 key>
# 或
DASHSCOPE_API_KEY=<百炼 key>
LLM_PLAN_PROVIDER=openai        # 让对话式修图用真模型规划（默认规则式）
LLM_API_KEY=<百炼 key>
LLM_MODEL=qwen-plus
MODERATION=qwen-vl              # 分享给别人之前建议开
PUBLIC_BASE_URL=https://你的域名 # 上游回拉图片要用，本地开发可留空
```

改完重启服务。顺序靠前的优先，失败自动降级到下一个。

### 分享给朋友之前必做

1. `JWT_SECRET` 换成随机值（`openssl rand -hex 32`）。
2. 上 HTTPS（`docker compose up -d --build`，Caddy 自动签证书）。**注意**：Caddyfile 用 `{$SITE_ADDRESS}` 取域名，而 compose 的 `web` 服务目前没把这个变量注入容器，不设就会退化成 `localhost` 自签（修复排在 [05](./05-修复与收尾计划.md) 任务 5.1）。
3. `COOKIE_SECURE=true`、`MODERATION=qwen-vl`。
4. 给每人设合理配额，确认 `DAILY_BUDGET_YUAN`。
5. 跑一次备份演练：`./deploy/backup.sh`，并确认能从备份文件恢复。**恢复脚本目前还没有**（`backup-db.mjs` 只做 `VACUUM INTO` 快照，且备份目录落在容器内），这块连同恢复演练排在 [05](./05-修复与收尾计划.md) 任务 5.3 —— 在补上之前别把这一步当作已通过。

## 10. 常见问题

**进度条一直不动 / 页面卡在"执行中"**
先刷新页面 —— 任务在服务端独立跑，**断线重连时错过的事件会自动补发**（新开的页面不重放历史事件，避免旧结果盖到当前文档上）。若刷新后仍卡住，多半是反向代理把 SSE 缓冲了，检查 Caddy 的 `flush_interval -1`。

**出来的是灰格子占位图**
Mock 模式，见 §0。

**提示"请先在画布上涂抹或框选要处理的区域"**
消除 / 局部替换必须有选区，见 §6。目前选区**只有涂抹笔刷**，矩形与套索还没开放。

**提示"今日次数已用完"**
等次日 0 点，或让管理员调高你的配额。

**换背景边缘毛糙**
优先用"纯色背景"（走颜色填充路径）。"先图层拆分再单独调主体层"目前还不成立 —— 拆分只落地主体层，背景层没接进画布（修复排在 [05](./05-修复与收尾计划.md) 任务 3.0）。

**导出后图片很小 / 有黑边**
导出按原始尺寸与当前图层状态生成；若图很小，检查是否先做了超分，以及导出倍率是否为 1×。

**手机能用吗**
工具箱能：上传、跑功能、看对比、导出都没问题。**编辑台在小屏上有已知问题**：≤860px 时右侧对话/图层面板会变成浮层并盖住画布，没有开合按钮（修复排在 [05](./05-修复与收尾计划.md) 任务 3.6）。触屏下的涂抹选区、图层、缩放也都没细调，正式修图还是在电脑上。

**图片安全吗**
两点要清楚：① 上传的图会传输给云端模型服务处理（阿里云 / 火山），不是纯本地；② 原图与结果都存这台服务器上，仅上传者与管理员可见。所以 **不要上传身份证、银行卡、合同等含个人信息的图片**。

## 11. 报错对照表

界面提示与含义一一对应，看到不认识的提示可以按代码查：

| 提示 / 代码 | 含义 | 你能做什么 |
| --- | --- | --- |
| `NEEDS_IMAGE` 这个功能需要先有一张图 | 没选工作图 | 先上传或在印样里选一张 |
| `NEEDS_MASK` 请先涂抹选区 | 缺选区 | 见 §6（矩形/套索未开放） |
| `QUOTA_EXCEEDED` | 个人次数用完、全站成本熔断，**或操作太频繁被限流** | 等次日 / 找管理员调配额；限流是几十秒后再试 |
| `PROVIDER_TIMEOUT` 模型超时 | 上游慢 | 点重试，通常一次就好 |
| `PROVIDER_UNAVAILABLE` 没有可用模型 | 没配 key 或该能力无上游支持 | 找管理员；或先用 Mock 走流程 |
| `PROVIDER_FAILED` 模型调用失败 | 上游报错 | 换个说法或稍后重试 |
| `MODERATION_REJECTED` | 内容审核未通过 | 换图或换描述；审核本身故障时会放行并记日志 |
| `PLAN_EMPTY` 这个需求我暂时做不到 | 指令超出工具范围 | 按提示改说法，或拆成几步 |
| `TOOL_PARAMS_INVALID` | 参数越界 | 按表单范围重填 |
| `FILE_TOO_LARGE` / `FILE_TYPE_UNSUPPORTED` | 上传超限或格式不对 | 压缩或转成 PNG/JPEG/WebP |
| `INVITE_INVALID` | 邀请码错或已用 | 找管理员要新的 |
| `UNAUTHORIZED` 登录状态已过期 | 会话失效 | 重新登录 |
| `CLIENT_TIMEOUT` 浏览器端没有响应 | 本地步骤没回执（页面被切走/关了） | 保持编辑台开着，重试该步 |
| `BAD_REQUEST` | 参数或画布数据不合法、缺字段 | 按提示改；表单里越界的值重填 |
| `FORBIDDEN` 跨站请求被拒绝 / 需要管理员权限 | 请求来源与站点不同源，或用普通账号访问管理端 | 用本站地址打开页面；管理操作换管理员 |
| `NOT_FOUND` | 图 / 文档 / 任务不存在，**或属于别人**（故意不区分，避免探测） | 回列表重选一张 |
| `BAD_CREDENTIALS` / `USERNAME_TAKEN` | 登录或注册被拒 | 核对密码 / 换用户名 |
| `TOOL_UNKNOWN` / `PLAN_NOT_APPROVABLE` / `PLAN_CYCLE` | 工具名不存在、计划已不在待确认状态、步骤成环 | 重新描述需求生成新计划 |
| `INTERNAL` 服务器内部错误 | 未预期异常（已修的四类畸形输入不再报这个） | 带上任务号或时间点找管理员查日志 |
