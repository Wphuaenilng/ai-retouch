## 0. 先确认一件事：现在是"真模型"还是"占位图"

默认配置（`.env` 里 `PROVIDER_PRIORITY=mock`）**不接任何模型 API**，所有 AI 功能返回一张带灰格边框的占位图。这不是坏了，是用来验证链路与界面交互的。

看到占位图 = 当前是 Mock 模式。想出真效果，需要管理员在 `.env` 里填 `ARK_API_KEY`（火山方舟 Seedream）或 `DASHSCOPE_API_KEY`（阿里云百炼万相），并把 `PROVIDER_PRIORITY` 改成 `seedream,mock`，然后重启服务。详见 [§9 管理员](#9-管理员)。

登录状态保留 30 天。退出用右上角「退出」。

## 2. 五分钟第一次修图

1. 进「工具箱」，点右上角 **上传新图**，选一张照片（PNG / JPEG / WebP，≤20MB）。
   **第一次上传会先弹一张「上传前须知」**：说清图片会交给哪个云端模型、什么东西会离开浏览器、服务器上留存什么。点「我知道了，继续上传」才真的传 —— 只做一次，且记在你的账号上（换浏览器会再问一次）。常驻版本在右侧栏「上传前须知」展开里，随时能回看。
   浏览器会先在本机压出一份"编辑副本"（最长边 2048）再上传，所以大图也不会卡。
2. 左侧选一个功能，比如 **抠图**。右侧参数默认值就能用，点 **抠图 · 约 ¥0.03**。
3. 中间出现 **显影中 42%** 的进度条 —— 数字来自服务端上报的真实进度（Mock 上游是固定的模拟节奏，不代表真实模型耗时）。
4. 完成后自动变成 **前后对比滑杆**：左右拖动中线看差别，左边是处理前，右边是处理后。
5. 满意就点 **进入编辑台** 继续细修，或 **存为新项目** 留着以后改。
6. 不想要了就点图片下方 **删掉这张**：服务器上的文件、数据库记录、画布上用到它的图层一起清掉，同一次上传的编辑副本与缩略图也跟着走。**删项目不带走原图**（同一张图可能被别的项目在用）。唯一还留着副本的地方是每日备份，14 天自动滚掉，急着清要找管理员。要整个账号走：右上角「账号」→ 注销账号（要再输一次用户名与密码，不可撤销，图片文件与配额记录一起删）。

一句话：**上传 → 选功能 → 执行 → 拖滑杆看对比 → 导出**。

>
> - **文生图选 2/4 张时会给你候选网格**：跑完在舞台下方列出 2/4 张小图，点一张就把它当当前图（几张都已经入库，切换不额外计费）。

> - **文生图同理去掉了"清晰度 2K/4K · 加价"**：runner 从不读这个字段，留着等于暗示"选 4K 会多收钱"而实际什么都不发生。

> - **图层拆分给两层（主体 + 背景）**：结果会真的落成两个图层进画布；`ocr` 开关目前只记录在结果里，没有文字层产出（已列入砍掉清单，见 05 §5）。
> - **多图融合不可用**：后端与注册表就绪，但"一次选多张图"的界面没做，提交会提示参数不完整。
>
> 单价是**参考值**，真实成本取决于上游计费；Mock 模式下记账为 ¥0。

### 本地功能（免费、即时、可撤销）

- **调色**：表单有 11 个参数，实际效果分三档（详见 [03-实现说明.md](./03-实现说明.md) §3.3）：
  - 真的生效：亮度、曝光、对比度、饱和度、色温与色调（用色相近似，不是白平衡级精度）；"黑白"= 饱和度 -1。
  - **近似实现**：高光/阴影被折进亮度，暗角与褪色是叠一层渐变/纯色矩形。
  - **暂时无效**：锐化（Konva 核心滤镜没有真锐化，任务 3.0/5.x 的 WebGL 管线才有）。
  - 参数范围：前 8 个 -1~1，锐化/暗角/褪色 0~1。**改完要提交才作用到图层**（可撤销），不是拖动中实时预览。
- **裁剪 / 变换**：比例裁剪、旋转、水平/垂直镜像。表单里的 `cropRect`（指定裁剪矩形）暂未开放。
- **导出**：PNG / JPEG / WebP，1× 或 2×，JPEG/WebP 可调质量。**导出按文档原始尺寸出图**，不受当前缩放与平移影响。

在工具箱点这三个本地功能，会直接把你带进编辑台 —— 因为它们需要画布。

## 5. 对话式修图（最省事的用法）

进入编辑台后，右侧就是对话框。直接说人话：

```
把背景换成米白摄影棚，裁成 1:1，再亮一点
```

会发生三件事：

1. **拆计划**：AI 给出步骤卡片（最多 6 步），标出哪几步是云端、哪几步是"本地"（本地步骤免费）。
2. **你把关**：点 **确认执行** 才开始；不想做就点 **取消**。
3. **逐步跑**：每步实时显示"完成 · 1.5s · ¥0.26"，画布跟着变。

### 出错了怎么办

某一步失败（常见是模型超时）时，**已完成的步骤不会丢**，后面的步骤标为已取消。此时你有三个选择：

- **重试本步**：只重跑失败的那一步，然后自动继续往下。
- **跳过并继续**：不要这一步的结果，直接做后面的。
- **取消**：整个计划停掉，画布停在当前状态（照样能撤销）。

### 怎么写指令效果好

| 想做的事 | 建议说法                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 改观感   | "再亮一点""暖一些""转黑白""加点暗角"（小幅度，AI 会翻译成 ±0.15 这类参数）      |
| 换背景   | "背景换成纯白"（纯色最稳）或"换成米白摄影棚，柔和顶光"                          |
| 局部处理 | **先在画布上涂抹选区**（见 §6），再说"去掉我圈起来的东西""把选区里换成深色木桌" |
| 改尺寸   | "裁成 1:1""扩成 16:9""放大 2 倍变清晰"                                          |

做不到的事（比如"把这张图做成 15 秒视频"）会明确拒绝并告诉你它能做什么，不会硬凑一个错误结果给你。

## 6. 选区（消除和局部替换的前提）

画布左下角工具条里有两种方式，产物都是同一张遮罩图，可以叠加：

**涂抹**

1. 点笔刷图标进入涂抹模式。
2. 在图上涂要处理的地方，白色区域就是要动的部分，半透明显示。
3. `[` 缩小、`]` 放大笔刷（也可拖工具条上的滑块）；点 × 清空重涂。
4. 松手自动上传为遮罩，屏幕下方提示"选区已就绪，可以执行消除或局部替换"。

**框选**

1. 点笔刷旁边的方框图标进入框选模式。
2. 按住拖出一个矩形，松手即成为选区（拖动过程中是半透明预览）。
3. 想要 L 形或不规则区域：先框大块，再切回涂抹补细节；点 × 全部清空。
4. 小于 2px 的误点会被忽略，不会清空已有选区。

涂抹比精确描边更好用 —— 模型会自动往外扩一点补全，稍微涂过界没关系。

## 7. 编辑台进阶

### 看片与对比

- **滚轮**：以光标为中心缩放；点 **适配** 回到整图。缩放百分比在画布左下角，图片像素尺寸在右下角。
- **手**（导轨最下方）：进入拖拽平移模式。
- **`\`** 或顶栏对比按钮：**前后对比**。左边显示原图、右边显示当前合成结果，拖动中线比较。

### 图层

- 点图层行选中；AI 结果会替换当前选中层的图源，所以"当前图层"决定结果落在哪。
- 眼睛图标显隐，× 删除（至少保留一层）。
- **接触印样**（底部胶片条）：每次 AI 结果都留一帧，点任意一帧就把当前层切回那一版 —— 相当于可视化的"历史版本"。

### 撤销与保存

- `Ctrl/⌘ + Z` 撤销，`Shift + Ctrl/⌘ + Z` 重做，最多 50 步。**AI 结果也能撤销**，所以放心试。
- 改动后约 1 秒自动保存，顶栏显示"未保存…"→"已保存 14:32"；`Ctrl/⌘ + S` 立即保存。
- 关掉页面不丢：项目列表里点进来就是上次保存的样子。

### 快捷键一览

| 键                   | 作用             |
| -------------------- | ---------------- |
| `Ctrl/⌘ + Z`         | 撤销             |
| `Shift + Ctrl/⌘ + Z` | 重做             |
| `Ctrl/⌘ + S`         | 立即保存         |
| `[` `]`              | 笔刷变小 / 变大  |
| `\`                  | 前后对比开关     |
| 滚轮                 | 以光标为中心缩放 |
| Enter / Shift+Enter  | 发送指令 / 换行  |

## 8. 配额、花费与限制

- 每人每天默认 **30 次** AI 调用（管理员可调），本地功能不计次。用完时右侧「配额」那行会写**还有多久重置**（比如"6 小时 30 分后重置"），报错里也会给出重置时刻的服务器时间。注意日切按**服务器本地时区**结算：容器跑在 UTC 时，国内用户实际是早上 8 点重置 —— 所以这里给的是"还有多久"而不是"明天 0 点"。
- 全站有 **每日成本熔断**（默认 ¥200）：触发后所有人都暂时不能用 AI 功能，这是防止误操作的保险。
- 上传限制：单张 ≤20MB、像素总量 ≤4000 万。服务端能收 PNG / JPEG / WebP / GIF，但**文件选择框只放开 PNG / JPEG / WebP**（GIF 需要先转格式）。
- 一次修图的实际花费：抠图约 ¥0.03，多数编辑约 ¥0.26，超分约 ¥0.12。按默认配额算，一个人一天全用满也就几块钱。

**看自己的用量**：顶栏"今日 12/30"；管理页能看到每人的花费。

**账号与密码**：顶栏「账号」里可以改密码。改完（以及点「退出」）**所有设备上的登录状态都会立刻失效**，需要重新登录 —— 这不是 bug，是为了让"改密"真的能把别人的会话踢掉。
另外：本次升级（引入会话版本号）之后，此前已经登录的会话需要重新登录一次。

## 9. 管理员

### 本机启动与停止

```bash
cd ai-retouch
cp .env.example .env     # 第一次
pnpm install
pnpm dev                 # 前端 5173 + 后端 8787，Ctrl+C 停止
```

首次启动会自动建库、按 `.env` 里的 `BOOTSTRAP_ADMIN_USERNAME / BOOTSTRAP_ADMIN_PASSWORD` 建管理员账号。

### 管理页（右上角「管理」，仅管理员可见）

- **今天**：成本 / 预算、队列水位、内容审核状态。
- **上游**：Seedream / 万相 / Mock 是否可用（没配 key 的显示"未配置 API Key"）。
- **邀请码**：一键生成 3 个，可选有效期（7 / 30 / 90 天 / 不限，默认 30 天）；点输入框即全选，方便复制发出去。下面列出还没被用掉的码和各自的到期日，过期的标红 —— 发出去的码能不能用，这里一眼看得清。
- **用户与配额**：直接改某个人的每日次数，失焦即保存。

### 每天两分钟的巡检

管理页是"当时看一眼"，长期跑要靠这条命令（不需要人开着页面）：

```bash
pnpm --filter @retouch/server cost-report            # 今天
pnpm --filter @retouch/server cost-report --date=2026-09-21
```

它会打出：当天任务数（成功/失败）、计费次数、成本对预算的百分比、每人花费前列、
按工具的成本、失败原因按错误码归类，以及有没有 `charged=0` 的账没结（那是漏退的征兆）。
**退出码是给它接通知用的**：`0` 正常、`2` 成本已达预算 80%、`3` 当天失败率过半，所以
`0 8 * * * … cost-report || 你的通知命令` 就够了。

注意日期口径：报表跟着**服务器本地日**切，容器默认 UTC 时国内是早上 8 点换一天。

### 出错了怎么查

每个请求都有一个短编号：响应头 `x-request-id`，服务端日志里的 `reqId` 字段。
500 错误会把编号直接写进提示里（`服务内部错误（编号 4f2a1c9b）`），截图发给管理员就能定位到那一行日志。
4xx 不带编号 —— 那些提示本来就是给你看的，不需要查日志。

### 接真实模型

编辑 `.env`：

```
PROVIDER_PRIORITY=seedream,mock
ARK_API_KEY=<火山方舟 key>
# 或
DASHSCOPE_API_KEY=<百炼 key>
# 或：OpenAI 兼容端点 / 中转站的 gpt-image。它只出文生图，编辑照旧归万相
#   PROVIDER_PRIORITY=openai_images,wanx
#   OPENAI_IMAGES_BASE_URL=https://你的中转站/v1
#   OPENAI_IMAGES_API_KEY=<中转站 key>
#   OPENAI_IMAGES_MODEL=gpt-image-2      # 以端点 GET /models 列出的名字为准
#   OPENAI_IMAGES_PRICE_YUAN=0.35        # 元/张：这类站不回 usage，成本全靠这个数，按你实际账单填
LLM_PLAN_PROVIDER=openai        # 让对话式修图用真模型规划（默认规则式）
LLM_API_KEY=<百炼 key>
LLM_MODEL=qwen-plus
MODERATION=qwen-vl              # 分享给别人之前建议开（见 §9.3 的取向说明）
# MODERATION_BLOCK_WORDS=...    # 提示词关键词表，逗号分隔；配了就整表替换默认名单
PUBLIC_BASE_URL=https://你的域名 # 上游回拉图片要用，本地开发可留空
```

改完重启服务。顺序靠前的优先，失败自动降级到下一个。

各家做得到的事不一样（下表的万相与 gpt-image 两行是 2026-09-28 拿真 key 实测的，Seedream 那行不是）：

| 上游 | 做得到的 | 做不到，会被拒 |
| --- | --- | --- |
| 百炼 通义万相 2.6 | 文生图、整图编辑（提示词编辑 / 换背景 / 老照片修复 / 去文字不带选区），一发约 **8s** | 涂抹或框选的**消除与局部替换**（上游不收遮罩）、超分、抠图 |
| 中转站 gpt-image | 只有文生图，一发约 **27s**（慢在还要从它给的 URL 把图拉回来）；`quality` 填了也不生效（站方静默忽略） | 编辑（它那个 `/images/edits` 一塞图就 502）、其余全部 |
| 火山方舟 Seedream | 按各家文档该有局部重绘与超分，**本仓还没拿真 key 验过**，别当已交付 | —— |

所以 `PROVIDER_PRIORITY=openai_images,wanx` 的意思是：文生图先问中转站、它失败就退到万相，编辑只有万相做得，而"消除"会直接报"没有可用的模型支持「inpaint」" —— 这是刻意的，不是坏了。想看占位图流程就把 `mock` 加进去（`openai_images,wanx,mock`），但要清楚那时候的图是程序画的格子，不是模型出的。

> 现在做不到的工具**按钮还照样摆在工具箱里**，点了才知道 —— 这条已登记为 [05](./05-修复与收尾计划.md) 的 D31，修好之后做不到的会置灰并写明原因，而不是让你去试。

### 分享给朋友之前必做

1. `JWT_SECRET` 换成随机值（`openssl rand -hex 32`）。
2. 上 HTTPS（`docker compose up -d --build`，Caddy 自动签证书）。域名写在 `.env` 的 `SITE_ADDRESS=`：compose 已把它注入 `web` 容器，**不设就直接报错退出**（以前会静默退化成 `localhost` 自签，站点等于没上线）。本地试跑填 `localhost:8080`。
3. `COOKIE_SECURE=true`、`MODERATION=qwen-vl`。要知道的两点：① 开了审核却没配 `LLM_API_KEY`，服务**直接拒绝启动**（否则表现是所有人都出不了图，查半天）；② 审核接口自己故障时是分档的——**上传放行**（上游抖一下不该锁死工作台），**成品图拒绝**（那张要发给别人看，宁停不错发），报 `MODERATION_UNAVAILABLE` 而不是冤枉用户违规。
4. 给每人设合理配额，确认 `DAILY_BUDGET_YUAN`。
5. 跑一次备份演练：`./deploy/backup.sh` 出快照 + 图片包，然后
   ```bash
   docker compose stop app
   docker compose exec app /app/deploy/restore.sh /data/backups/latest.db --force
   docker compose up -d app
   ```
   `restore.sh` 包了一层 `restore.mjs`：校验快照可读、报出行数与 `user_version`、**目标库已存在时必须 `--force`** 才覆盖，`--images <images-*.tgz>` 顺带还原图片目录。跑通的标准是恢复后能登录并看到旧图。

## 10. 常见问题

**进度条一直不动 / 页面卡在"执行中"**
先刷新页面 —— 任务在服务端独立跑，**断线重连时错过的事件会自动补发**（新开的页面不重放历史事件，避免旧结果盖到当前文档上）。若刷新后仍卡住，多半是反向代理把 SSE 缓冲了，检查 Caddy 的 `flush_interval -1`。

**出来的是灰格子占位图**
Mock 模式，见 §0。

**提示"请先在画布上涂抹或框选要处理的区域"**
消除 / 局部替换必须有选区，见 §6。选区有两种：**涂抹笔刷**和**矩形框选**，可以叠加使用（先框大块再涂掉不该要的部分）。

**提示"今日次数已用完"**
等下一次日切（界面会写还有多久），或让管理员调高你的配额。

**换背景边缘毛糙**
优先用"纯色背景"（走颜色填充路径）。"先图层拆分再单独调主体层"目前还不成立 —— 拆分只落地主体层，背景层没接进画布（修复排在 [05](./05-修复与收尾计划.md) 任务 3.0）。

**导出后图片很小 / 有黑边**
导出按原始尺寸与当前图层状态生成；若图很小，检查是否先做了超分，以及导出倍率是否为 1×。

**手机能用吗**
工具箱能：上传、跑功能、看对比、导出都没问题。**编辑台在小屏上有已知问题**：≤860px 时右侧对话/图层面板会变成浮层并盖住画布，没有开合按钮（修复排在 [05](./05-修复与收尾计划.md) 任务 3.6）。触屏下的涂抹选区、图层、缩放也都没细调，正式修图还是在电脑上。

**图片安全吗**
两点要清楚：① 上传的图会传输给云端模型服务处理（阿里云 / 火山），不是纯本地；② 原图与结果都存这台服务器上，仅上传者与管理员可见。所以 **不要上传身份证、银行卡、合同等含个人信息的图片**。
